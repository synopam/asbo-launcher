# Asbo Launcher

Launcher Minecraft Java Edition untuk mengelola akun, instance, dan konten game dari satu aplikasi desktop.

## Instalasi

1. Unduh installer **Asbo Launcher Setup (.exe)**.
2. Buka file `.exe` dan ikuti petunjuk pemasangan. Pilih folder instalasi jika diminta.
3. Jalankan **Asbo Launcher** dari Start Menu atau shortcut desktop.
4. Masuk atau daftar akun Asbo, atau pilih **Lanjutkan sebagai Guest**.
5. Di Beranda, tekan **Buat Instance**, atur versi Minecraft dan mod loader, lalu pilih instance untuk bermain.

Tidak perlu memasang Node.js atau menjalankan perintah npm. Launcher akan mengunduh file game yang diperlukan saat pertama kali dijalankan. Pastikan koneksi internet tersedia dan Java yang sesuai dengan versi Minecraft sudah terpasang.

## Fitur

- **Banyak instance:** pisahkan versi Minecraft, mod, texture pack, dan shader per instance.
- **Pilihan mod loader:** Vanilla, Fabric, Forge, NeoForge, dan Quilt.
- **Akun Minecraft:** tambahkan akun Offline, Microsoft, atau Ely.by, lalu pilih akun untuk bermain.
- **Modrinth:** lihat rekomendasi populer atau cari mod, texture pack, dan shader yang cocok dengan instance; gunakan tombol halaman untuk menelusuri hasil.
- **Teman dan chat:** kirim permintaan pertemanan dan bertukar pesan menggunakan akun Asbo.
- **Voice room:** buat atau gabung ke room suara dengan maksimal empat orang.
- **Log launcher dan game:** lihat status unduhan dan output Minecraft dari menu **Log**.
- **Folder game:** buka folder instance yang sedang dipilih.

## Akun dan privasi

Akun Asbo digunakan untuk layanan launcher seperti teman, chat, dan voice room. Akun tersebut terpisah dari akun Minecraft. Kamu dapat menggunakan launcher sebagai Guest tanpa mendaftar, tetapi fitur sosial memerlukan akun Asbo.

Sesi akun Microsoft dan Ely.by disimpan secara terenkripsi menggunakan penyimpanan aman sistem operasi jika tersedia. Password Ely.by tidak disimpan. Mode Offline ditujukan untuk bermain lokal dan tidak memberikan lisensi Minecraft atau akses ke multiplayer server resmi. Ely.by memerlukan koneksi internet; pada peluncuran pertama, launcher mengunduh authlib-injector dari host resminya dan memeriksa checksum unduhan.

Voice chat menggunakan WebRTC peer-to-peer. Karena koneksi langsung antaranggota, alamat IP publik dapat terlihat oleh peserta lain; sebagian jaringan mungkin memerlukan TURN relay agar panggilan berhasil.

## Menggunakan Modrinth

1. Buat atau pilih instance yang sesuai.
2. Buka menu **Modrinth**.
3. Pilih kategori **Mod**, **Texture Pack**, atau **Shader**. Rekomendasi populer akan muncul otomatis sesuai versi game dan loader.
4. Gunakan kotak pencarian bila ingin mencari proyek tertentu, lalu navigasikan hasil dengan tombol **Kembali** dan **Berikutnya**.
5. Tekan **Pasang** pada konten yang ingin ditambahkan ke instance terpilih.
